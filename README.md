# ポケコロジャーニー

双六 × 30秒なぞりパズル × ポケモンカード収集のプロトタイプ。

## 遊び方
サイコロで進み、同じ属性の隣接ピースを3個以上なぞって離すと攻撃。2秒以内の消去でコンボ。野生を倒すと捕獲、トレーナーに勝つとボールを獲得。図鑑から最大5匹を編成できます。育成・固有スキルはありません。

## 実行
ビルド不要。`python3 -m http.server 8000` で起動し、ブラウザで開いてください。セーブはlocalStorage（ブラウザ・URLごと）です。別タブへ移動した戦闘は終了します。

## GitHub Pages
Settings → Pages → Deploy from a branch → main / (root) を選択。非公開リポジトリでのPages利用可否はGitHubの契約に依存します。公開設定は自動変更していません。

## 素材
ユーザー提供のポケモン画像9点をサンプルとして使用。非公式ファンプロトタイプ。
