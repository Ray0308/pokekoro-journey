# ポケコロジャーニー

Ver. 0.4.0。スマートフォン縦画面を中心にした、すごろくと属性パズルのWebゲーム。

## 遊び方

- サイコロのボタンを押して回し、離すと出目が決まり移動する。
- 野生・トレーナーのマスで30秒のパズルに挑戦。同じ属性を3個以上つなぎ、最後にまとめて攻撃する。
- 出発地点はポケモンセンター。パーティーは最大6匹。
- ボス勝利で次のエリアへ進む。敗北時はゴールで再挑戦できる。
- 第1マップのトキワの森から、ニビシティ・8ジム・主要ダンジョン・四天王へ進み、ワタル勝利後にハナダの洞窟へ進み、最深部に勝利すると旅を完了する。全29エリア。
- 「旅のきろく」で現在地、クリア済みエリア、8つのジムバッジを確認する。

詳しい旅順と仮素材の範囲は [CAMPAIGN.md](CAMPAIGN.md) を参照。

## 素材の状態

第2マップ以降の背景・人物画像・手持ちは暫定。背景は既存の森・草原と `assets/map/placeholders/` の仮SVGを使い、人物とポケモンは既存素材で代用している。原作の手持ちを再現した状態ではない。ユーザー提供素材が届いたら `map-config.js` の各エリアを差し替える。既存のロゴ、タイトル背景、主人公などは維持している。

## 設定と構成

- `index.html`：画面、ダイアログ、メニュー。
- `app.js`：すごろく、バトル、捕獲、エリア進行、セーブ。
- `map-config.js`：`MAP_ORDER` に旅順、`MAPS` に背景・配色・ボス・バッジ・次エリアを設定。`MAP_ALIASES` は旧IDの移行用。
- `style.css` / `map.css`：ゲームとマップ・旅のきろくの表示。
- `title-config.js` / `title.js` / `title.css`：タイトル専用の素材設定と演出。
- `version.js`：バージョンの単一設定。更新時はHTMLのキャッシュ用クエリとCHANGELOGも更新する。

`MAPS` の `boss.image` / `boss.icon` / `boss.pokemonId` を変えるとボスの人物・コマ・手持ちを差し替えられる。`boss.pokemonId` は全国図鑑番号1〜1025。未登録の名前・画像・タイプは番号表示で代用し、pokemon-data.js の POKEMON_OVERRIDES で後から補完できる。`route` は屋外・ダンジョンの2種類で、各15マス。

## セーブ

`pokekoro-v1` をlocalStorageに保存。図鑑、パーティー、ボール、現在地、クリア済みエリア、移動待ち状態を引き継ぐ。旧 `meadow` は `pewter-city`（ニビシティ）へ移行する。サウンド設定は `pokekoro-title-v1` に別保存する。

## ボール

道具マスはモンスターボール80%（3個）、スーパー17%（1個）、ハイパー3%（1個）。通常トレーナー勝利の固定報酬と敗北時の参加報酬は維持。マスターはボス勝利時のみ3%の追加報酬。

捕獲率はパズルの成果に応じて、モンスター40〜80%、スーパー60〜95%、ハイパー75〜99%、マスター100%。`BALLS` / `BALL_DROPS` で設定する。

## ローカル起動

静的なHTML/CSS/JavaScript構成で、ビルドや追加ライブラリは不要。

```sh
python -m http.server 8000
```

`http://localhost:8000/` を開く。公開はGitHub Pagesを使用する。

## タイトルBGM
ユーザー提供のオープニングMP3を assets/audio/title-opening.mp3 に原音のまま配置。title-config.js の audio でパスと音量を管理する。タイトルのみでループし、サウンドOFF・冒険開始・ページ非表示時には停止、タイトル復帰で再開する。ブラウザが自動再生を制限する場合は、タイトルで最初にタップした後から再生する。

冒険スタートでゴンベの鳴き声と歩行演出を同時に開始し、BGMは画面遷移まで2.4秒かけてフェードアウトする。連打は無視し、画面を離れた場合は演出を取り消してタイトルへ戻す。音源パス・フェード時間はtitle-config.jsで設定する。

## マップBGM
map-audio.js が assets/audio/map-adventure.mp3 をマップとメニューでループ再生する。タイトル・ダイアログ・非表示時には停止。MAP_AUDIO（map-config.js）で音源と音量を設定する。音源は既存曲を使わず、本作向けに作った16小節のオリジナル・チップチューン。生成用スクリプトは scripts/compose-map-music.cjs（Nodeで /tmp/map-adventure.wav を生成後、ffmpegでMP3化）。

## 全国図鑑1025枠
pokemon-data.js に全国図鑑番号1〜1025の枠を用意。既存9匹以外は名前・画像・タイプを登録せず、番号だけで遭遇・捕獲・編成する。図鑑は24件ずつ表示。詳細はPOKEDEX.md。
