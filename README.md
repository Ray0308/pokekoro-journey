# ポケコロジャーニー

双六 × 30秒なぞりパズル × ポケモンカード収集のプロトタイプ。

## 遊び方
サイコロで進み、同じ属性の隣接ピースを3個以上なぞって攻撃パワーをためます。2秒以内の消去でコンボ。30秒後にためた力で一斉攻撃。野生を倒すと捕獲、トレーナーに勝つとボールを獲得。図鑑から最大6匹を編成できます。育成・固有スキルはありません。

## 実行
ビルド不要。`python3 -m http.server 8000` で起動し、ブラウザで開いてください。セーブはlocalStorage（ブラウザ・URLごと）です。別タブへ移動した戦闘は終了します。

## GitHub Pages
Settings → Pages → Deploy from a branch → main / (root) を選択。非公開リポジトリでのPages利用可否はGitHubの契約に依存します。公開設定は自動変更していません。

## 素材
ユーザー提供のポケモン画像9点をサンプルとして使用。非公式ファンプロトタイプ。

## バージョンと制作クレジット
現在は Ver. 0.2.18。ブランド：Ray Edu Labo。制作/原案：株式会社ムリなもんはムリ。素材収集：パパ。原画：ポケモン。テスト：山田。バージョン表示は `version.js` に集約し、更新内容は [CHANGELOG.md](CHANGELOG.md) に記録します。

## タイトル画面
`title-config.js` が素材パス、初期設定、アニメーション速度を管理します。`title.js` が雲・主人公・開始演出とオプションを扱い、`title.css` はゲーム本体から独立しています。
タイトル背景はユーザー提供の背景画像です。雲は独立したレイヤーでゆっくり動かします。素材の詳細は [assets/title/README.md](assets/title/README.md) を参照。青い相棒は正式な相棒として常に表示します。オプションはサウンド切替のみです。設定はゲームセーブとは別の `pokekoro-title-v1` に保存します。
