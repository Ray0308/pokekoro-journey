# ポケコロジャーニー

Ver. 0.9.1.35。スマートフォン縦画面を中心にした、すごろくと属性パズルのWebゲーム。

## 遊び方

- サイコロのボタンを押して回し、離すと出目が決まり移動する。
- 野生・トレーナーのマスで30秒のパズルに挑戦。同じ属性を3個以上つなぎ、最後にまとめて攻撃する。
- 出発地点はポケモンセンター。パーティーは最大6匹。
- ボス勝利で次のエリアへ進む。敗北時はゴールで再挑戦できる。
- 第1マップのトキワの森から、ニビシティ・8ジム・主要ダンジョン・四天王へ進み、ワタル勝利後にハナダの洞窟へ進み、最深部に勝利すると周回クリアし、トキワの森へ戻る。全29エリア。
- 「旅のきろく」で現在地、クリア済みエリア、8つのジムバッジを確認する。

詳しい旅順と仮素材の範囲は [CAMPAIGN.md](CAMPAIGN.md) を参照。

## 素材の状態

第2マップ以降は、ニビジムの背景とタケシ本人の提供画像を除き、背景・人物画像・手持ちが暫定。背景は既存の森・草原と `assets/map/placeholders/` の仮SVGを使い、人物とポケモンは既存素材で代用している。原作の手持ちを再現した状態ではない。ユーザー提供素材が届いたら `map-config.js` の各エリアを差し替える。既存のロゴ、タイトル背景、主人公などは維持している。

## 設定と構成

- `index.html`：画面、ダイアログ、メニュー。
- `app.js`：すごろく、バトル、捕獲、エリア進行、セーブ。
- `map-config.js`：`MAP_ORDER` に旅順、`MAPS` に背景・配色・ボス・バッジ・次エリアを設定。`MAP_ALIASES` は旧IDの移行用。
- `style.css` / `map.css`：ゲームとマップ・旅のきろくの表示。
- `title-config.js` / `title.js` / `title.css`：タイトル専用の素材設定と演出。
- `version.js`：バージョンの単一設定。更新時はHTMLのキャッシュ用クエリとCHANGELOGも更新する。

`MAPS` の `boss.image` / `boss.icon` / `boss.pokemonId` を変えるとボスの人物・コマ・手持ちを差し替えられる。`boss.pokemonId` は全国図鑑番号1〜1025。未登録の名前・画像・タイプは番号表示で代用し、pokemon-data.js の POKEMON_OVERRIDES で後から補完できる。`route` は屋外・ダンジョンの2種類で、各15マス。

## セーブ

`pokekoro-v1` をlocalStorageに保存。図鑑、パーティー、ボール、現在地、クリア済みエリア、移動待ち状態を引き継ぐ。旧 `meadow` は `pewter-city`（ニビシティ）へ移行する。サウンド設定は `pokekoro-title-v1` に別保存する。

## ボール

道具マスはモンスターボール80%（3個）、スーパー17%（1個）、ハイパー3%（1個）。通常トレーナー勝利の固定報酬と敗北時の参加報酬は維持。マスターはボス勝利時のみ3%の追加報酬。

捕獲率はパズルの成果に応じて、モンスター40〜80%、スーパー60〜95%、ハイパー75〜99%、マスター100%。`BALLS` / `BALL_DROPS` で設定する。

## ローカル起動

静的なHTML/CSS/JavaScript構成で、ビルドや追加ライブラリは不要。

```sh
python -m http.server 8000
```

`http://localhost:8000/` を開く。公開はGitHub Pagesを使用する。

## タイトルBGM
ユーザー提供のオープニングMP3を assets/audio/title-opening.mp3 に原音のまま配置。title-config.js の audio でパスと音量を管理する。初期タイトルは「－ タップしてね －」を表示し、タップでメニューとBGMを同時に開始する。無操作の自動再生は行わない。タイトルのみでループし、サウンドOFF・ゲーム画面への遷移・ページ非表示時には停止する。タイトルへ戻る場合もタップ案内から再開する。

冒険スタート押下直後にゴンベの鳴き声を再生し、右からサイコロが投げ込まれる。停止後に歩行演出を開始し、BGMは画面遷移まで通常音量で再生し、切り替え時に停止する。連打は無視し、画面を離れた場合は演出を取り消してタイトルへ戻す。音源パス・歩行時間・鳴き声の開始オフセットはtitle-config.jsで設定する。鳴き声は事前デコードしたWeb Audioバッファを押下時に再生し、非対応時はHTML音声へフォールバックする。

## マップBGM
map-audio.js が assets/audio/map-adventure.mp3 をマップとメニューでループ再生する。タイトル・ダイアログ・非表示時には停止。MAP_AUDIO（map-config.js）で音源と音量を設定する。音源は既存曲を使わず、本作向けに作った16小節のオリジナル・チップチューン。生成用スクリプトは scripts/compose-map-music.cjs（Nodeで /tmp/map-adventure.wav を生成後、ffmpegでMP3化）。

## 全国図鑑1025枠
pokemon-data.js に全国図鑑番号1〜1025の枠を用意。既存9匹以外は名前・画像・タイプを登録せず、番号だけで遭遇・捕獲・編成する。図鑑は24件ずつ表示。詳細はPOKEDEX.md。

## 虹のチケットと虹の雲
通常29マップを無限周回する。通常ボス勝利時に2%で虹のチケットを追加ドロップ。「旅のきろく」または獲得画面から1枚使用して虹の雲へ入場。草むらは準伝説70%・伝説25%・幻5%のカテゴリ抽選後、各番号から抽選する。ボスは伝説・幻の番号から選び、捕獲可能。ボス戦の勝敗・撤退にかかわらず、チケット獲得元の次マップへ帰還する。獲得元・戻り先・滞在中のボス番号と終了状態をセーブに保存する。設定はrainbow-config.js。準伝説等の分類だけを番号で管理し、種族名・タイプ・実画像は追加していない。UB・パラドックス・600族は専用表へ含めない。背景・チケット画像は差し替え可能なSVG。

## 開閉式の図鑑
右上メニューの「ずかん」から赤い図鑑を開き、画像・番号・説明を閲覧できる。前後のボタンと番号指定で1〜1025へ移動する。カードも詳細図鑑を開く操作となり、編成は図鑑内の専用ボタンで行う。フシギダネだけにユーザー提供の説明を登録済み。読み上げは端末のSpeechSynthesisによる日本語音声で、OSの声質に依存する。説明の追加はpokemon-data.jsのdescription、表示と読み上げ制御はpokedex.js / pokedex.css。

## デバッグ
タイトルの隅からマップ・開始位置・虹のチケット確定を選択できる。通常セーブとは別保存。無効化はindex.html末尾のdebug.jsのscript行をコメントアウトする。詳細はDEBUG.md。

## マップのメニュー
冒険マップをメイン表示とし、右上のハンバーガーメニューに「ずかん・ポケモン・どうぐ・バッジ・せってい」をまとめる。外側タップ・再タップ・Escapeで閉じる。「タイトルへ戻る」は設定内。game-menu.js / game-menu.css が操作と表示を担当し、メニュー・道具・設定中もマップBGMを維持する。
