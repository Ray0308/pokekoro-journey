## 未完了・調整対象

### 合意済みで、仕上げが残るもの

- 仮背景11マップの専用素材化。ユーザーから素材を受け取ったマップを順次仕上げる。
- 別マップの画像を流用しているニビシティ・サファリゾーン・23ばんどうろ・トキワジムの背景見直し。
- タイトルの雲は `assets/title/placeholders/clouds.webp` を使用中。差し替え対象として残る。
- オープニングの台詞の最終稿。現時点では `opening-config.js` の暫定案。
- HP、出現・獲得・捕獲・交換の量、技倍率やコスト等のまとめたバランス調整。個々の素材変更に混ぜて変更しない。
- 古い説明資料と未使用CSSの整理。下記の相違を先に確認する。

### 現行機能に含めていないもの

- 原作の全習得技の選択・付け替え、特性による戦闘効果、進化ツリーの画面・網羅的な進化連携。
- 味方の個別HP、個体値・努力値、原作そのままのPP・命中・状態異常・ダメージ式。

これらは「PokéAPIに項目がある」ことと「本作に実装する合意がある」ことを分けて扱う。自動的に次の作業へ追加しない。

- リリース0.9.2.50で、ふたごじま・ポケモンタワーを390×664、320×568、844×390で確認。画像寸法、15マス、入口/ボス座標、保存位置の表示、戦闘背景を確認した。
- GitHub Pagesの反映後、両マップを公開先の390×664でも確認した。
- 0.9.2.45の30マス化では `npm test`、30マスの落下・全補充、部分/全盤面変更スキルを検査。通常タップ、最下段の消去、無効/0ダメージ、技、連戦も確認した。
- その後の戦闘UI変更では待機ぼかしの解除、中央ボタン、タイプ順、カウントダウンの色と出始めの不透明度を確認した。
- 0.9.2.50の構文・整形検査は成功。画像だけの変更で、毎回ゲーム全体の数値テストを再実行したという意味ではない。
- 過去のブラウザ補助スクリプトは `/tmp`、画像は作業環境の `/workspace` に残っている場合がある。永続的なテスト成果物として存在を前提にしない。恒久的なルール検査はリポジトリの `tests/` を使う。

## 次の作業と再開方法

1. 新しいユーザー指示・素材を確認する。素材指定があればそのマップを優先する。
2. 未着手の仮背景または既存資料の整理を、1項目ずつ選ぶ。数値調整は別作業として合意する。
3. 現在の差分と公開mainを確認し、作成済みコードを捨てずに続ける。
4. 対象のコード・データ・生成物を絞って変更し、実際の入力と旧セーブへの影響を確認する。
5. 公開する場合は検証済みの差分だけを反映し、公開先の版と画面を確認して報告する。

新しい機能の実装途中として残っているふたごじま・ポケモンタワー作業はない。両方とも0.9.2.50で公開済み。今回の未完了は「古い中断メッセージ」だけから推測せず、本書と公開版で判断する。
