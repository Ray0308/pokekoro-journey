# 開発状況・引き継ぎ

更新日: **2026-11-18**。ゲームの確認済み公開版: **0.9.2.64**。

このファイルを、進捗・残タスク共有の入口として更新する。「公開済み」「ローカル実装済み・未公開」「未着手」「未確認」を区別し、予定を実装済みとして扱わない。0.9.2.53の機能公開に合わせて更新した。

## 技アニメーション（0.9.2.55）

攻撃・強化・防御・盤面変更・サポート・復活を共通演出関数で表示する。盤面変更中は技解説で隠していたcanvasを戻し、変更したマスを発光。演出中の追加発動は禁止し、撤退時はキャンセル。低モーションでは短い発光に置換する。技のルールとマスタは変更していない。PC・スマホ寸法のブラウザ検証と既存ルールテストを実施。実機Safari／Androidでの見た目は引き続き未確認。

## 反撃アニメーション（0.9.2.54）

敵の踏み込み→狙われた仲間へ光→命中後にひんし表示、の順で表示。ガードは青い盾、動きを減らす設定では移動せず短い発光。通常戦と専用練習で共通の演出関数を使う。入力を奪わず、操作中の盤面を隠さない。反撃対象・ひんし・技・防御の判定は既存ルールのまま。

変更元: `battle-feedback.js/css`、接続: `battle-turns.js` と `practice.js`。キャンセル可能なWeb Animationsと `battleEpoch`／練習generation照合で古い処理を止める。通常命中・防御・低モーション・撤退時の掃除を `tests/counter-animation-browser.cjs` で検証できる（Playwrightは任意の環境依存）。
