# 初回オープニング

`opening-config.js` が暫定台詞、`opening-rules.js` が保存・報酬、`opening.js` が画面と練習の接続を担当する。

新規セーブはゴンベ（446）のみから開始。研究所で001/004/007を選び、借りたニドラン♂（032）で10秒の実盤面を練習する。同属性を3個以上つないで離す操作が1回できれば成功。消せなくても失敗ペナルティなしで再挑戦できる。ピカチュウ（025）の投球は既存演出を使い、抽選・所持ボール消費・通常報酬処理を通さず必ず成功する。

ニドラン♂は `PokekoroTurns.aliveParty()` の練習分岐で参照するだけで、所持・遭遇・パーティーのデータには入れない。完了時にゴンベ・選択した御三家・ピカチュウを登録し、通常8個／スーパー2個を一度だけ渡す。ライバルの既存抽選仕様・通常戦闘の難易度は変更しない。

`state.opening` は version / stage / starterId / pokedexReceived を保存する。選択・台詞進行ごとに保存。パズル中の再読込は練習開始前、投球中は投球前から再開する。既存の有効セーブに opening がなければ完了扱いとし、所持や進行、報酬を変更しない。デバッグ開始時は案内を出さない。

`npm test` に保存移行・御三家3種・報酬の冪等性検査を含める。ブラウザでは実際のポインター操作、未消去時の再挑戦、途中再読込、確定捕獲、図鑑受け取り、スマートフォン縦横表示と旧セーブ継続を確認した。

画像: ユーザー提供のオーキド博士と研究所をWebPに形式変換して使用。ポケモンは既存のローカル図鑑画像を参照する。
