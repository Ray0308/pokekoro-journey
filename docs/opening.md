# 初回オープニング

`opening-config.js` が台詞（今回追加分はユーザー承認済み）、`opening-rules.js` が保存・報酬、`opening.js` が画面と練習の接続を担当する。

新規セーブはゴンベ（446）のみから開始。研究所で001/004/007を選び、借りたニドラン♂（032）で10秒の実盤面を練習する。同属性を3個以上つないで離す操作が1回できれば成功。消せなくても失敗ペナルティなしで再挑戦できる。ピカチュウ（025）の投球は既存演出を使い、抽選・所持ボール消費・通常報酬処理を通さず必ず成功する。

ニドラン♂は `PokekoroTurns.aliveParty()` の練習分岐で参照するだけで、所持・遭遇・パーティーのデータには入れない。完了時にゴンベ・選択した御三家・ピカチュウを登録し、通常8個／スーパー2個を一度だけ渡す。ライバルの既存抽選仕様・通常戦闘の難易度は変更しない。

`state.opening` は version / stage / starterId / pokedexReceived を保存する。選択・台詞進行ごとに保存。パズル中の再読込は練習開始前、投球中は投球前から再開する。既存の有効セーブに opening がなければ完了扱いとし、所持や進行、報酬を変更しない。デバッグ開始時は案内を出さない。

`npm test` に保存移行・御三家3種・報酬の冪等性検査を含める。ブラウザでは実際のポインター操作、未消去時の再挑戦、途中再読込、確定捕獲、図鑑受け取り、スマートフォン縦横表示と旧セーブ継続を確認した。

画像: ユーザー提供のオーキド博士と研究所をWebPに形式変換して使用。ポケモンは既存のローカル図鑑画像を参照する。

### 保存・互換性

- 新規 `opening.version` は2。アプリ版番号とは別の初回イベントの経路識別子。
- 確定済みの主人公名は通常状態の `state.playerName`。名前はこのプロパティから会話・UIへ参照できる。旧セーブで未設定の場合は `undefined` を許容する。
- 入力中は `state.opening.nameDraft`、段階は既存 `opening.stage` の `nameInput/nameConfirm`。再読込で下書き・確認段階を復元する。
- 前後の空白を除去し、空白のみ・8文字超を拒否。`Intl.Segmenter` が使える場合は見た目の文字単位、非対応環境ではコードポイント単位で数える。文字種の限定は行わず日本語・英数字を入力できる。
- 「いいえ」は下書きを保持して入力へ。「はい」で `OpeningRules.confirmName()` が `playerName` と `nameWelcome` 段階を同時に確定し、保存する。下書きは削除し、再確定を防ぐ。
- 日本語変換中のEnterは送信しない。名前は `textContent` で表示し、HTMLや置換記号として解釈しない。
- 旧版（version 1／版なし）の途中セーブは従来の `friend → lab → world → choose` 経路を維持。完了済み・初回情報なしの有効旧セーブにも名前入力を強制しない。
- 通常／デバッグの保存先・分離処理は変更しない。デバッグは引き続き初回案内を抑止。セーブ削除後は名前未設定の新規状態になる。
