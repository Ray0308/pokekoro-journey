# 初回オープニング（0.9.2.91）

2026-11-21更新。台詞はopening-config.js、進行/保存/報酬はopening-rules.js、画面と練習接続はopening.js、文字パネルはopening-name.js。

## 新しい導入

新規opening.version=5。研究所でオーキドの紹介→世界の説明→名前決定→ゴンベ紹介→プレイヤーが同行へ誘う→御三家選択。

ゴンベは研究所で博士が世話をしているポケモンとして紹介。外の世界で経験をさせたいという博士の説明を受け、「ゴンベ、いっしょにいこう！」を押すことで初めてowned/party/seenへ446を追加する。お菓子・突然来る・すぐ懐く台詞とクッキー表示は使わない。新規owned/partyは同行まで空。同行処理は冪等で、研究所へ戻す・完了者へやり直しを強制する変更はない。

名前選択は指定順に「じぶんできめる／グリーン／レッド／レン」。プリセットも名前確認のはい/いいえを通す。いいえなら4択へ戻る。自分で決める場合は提供画像を参考にした10列の文字パネル。カタカナが初期表示、ひらがな・英数字へ切替、小文字・長音・濁点/半濁点・1文字削除・おわりを持つ。スマホのソフトキーボードを開くテキスト欄は置かない。

最大8文字は従来どおり。見た目の文字単位で数え、空白のみは不可。カスタム確認のいいえは下書きを保持してパネルへ戻る。文字種と下書きは選択ごとに保存。文字ボタンはTabと矢印/Enter、削除はボタン/Backspaceでも操作できる。名前はtextContentで表示する。

## 保存・互換性

- state.playerNameが確定名。opening.nameDraft/nameMode/nameSourceが未確定の下書き・文字種・選択元。はいで名前とnameWelcomeを同時に保存、下書きと選択元を削除する。
- 空partyの保存受入はversion=4/5、同行前の既知ステージ、御三家未選択、owned空に限定。通常の破損した空編成を認めない。
- 旧version 1/2/3の途中経路と完了セーブを維持する。未完了v4の御三家決定直後〜練習はv5へ移行する。完了済み/初回情報なしの有効旧セーブへ導入・名前・初回報酬を強制しない。
- 旧meet/friendの表示にもお菓子・自動で懐く説明を残さない。旧途中から名前入力へ来た場合も新しいパネルを表示できる。
- 本編の通常/デバッグ保存先と分離、既存所持・在庫・進行は維持する。

001/004/007を選び、ゴンベと一緒に[研究所の模擬戦](PRACTICAL_TUTORIAL.md)を行う。相手は博士のピカチュウ。なぞる/10秒の攻撃/溜まった技を同じ編成・実ゲージで試し、博士からピカチュウを譲り受けてボール操作へ。図鑑と一度だけの初期報酬後は御三家・ゴンベ・ピカチュウの順。強制並べ替えは省き、最初のサイコロを実操作して本編へ。通常8個/スーパー2個の報酬は変更しない。旧経路の貸与練習と完了セーブは保持する。
