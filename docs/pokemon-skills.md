# 個別技のデータと計算

## データと生成

`data/pokemon-skills.json`が編集元。提供された「代表技候補」の1025種と「技能力案」の668技を
2026-11-14時点で読み出し、文章ではなく構造化した効果設定へ変換した。
名前・タイプ・原作の物理/特殊分類はPokéAPI固定版
`8a92bfa7dab2f12b84b5d151562f9857c133ff30`の`moves.csv`を参照する。
元シートのID・範囲と固定版URLはデータの`source`に記録する。

`npm run skills:generate`で`pokemon-skills.generated.js`を生成する。
`npm run skills:check`でID、全国図鑑番号1〜1025の全割当、6系統、コスト、分類、対象、
倍率等の必須項目と生成物を検査する。未検査の文章を解析してゲーム中に動かさない。
668技のうち492技が現在の代表技として割り当てられており、残りは候補技設定。
全ポケモンは1つの代表技を持つ。技の付け替え・全習得技の選択は導入していない。

「一次案」「要調整」はバランス上の暫定状態。原作完全再現を意味せず、全技を自動で「採用」へ変更しない。
ユーザーが個別合意した「たくわえる」「つるのムチ」は採用として区別する。

## 実行と画面

`pokemon-skill-rules.js`が対象候補・使用可否・ダメージ予測・発動を共通化する。
`battle-turn-rules.js`は10秒ターン、ひんし、端数ゲージ、反撃と戦闘内状態を扱う。
`battle-turns.js`は対象選択、入力ロック、演出、勝敗、相手交代を接続する。
技と次へボタンはスクロール欄の外へ固定し、小画面でも常に押せるようにする。
図鑑のつよさ詳細でも代表技・コスト・効果を表示し、未遭遇では情報を出さない。

技ごとのコスト（8〜24）がそのままゲージ上限。消去による速度補正は素早さを使い、
直接支援による+6/+8/+3には速度補正を掛けない。
`usedTurn`で同じ仲間の連打、`supportTurn`で支援連鎖、`reviveUsed`で複数の復活持ちによる二重復活を防ぐ。
元パーティーやセーブ形式は変更しない。新しい戦闘では全員復帰し、戦闘内予約・制限も初期化する。

## 効果の扱い

- 通常攻撃技：技のタイプ・物理/特殊で、種族値から求めた本作火力×技倍率×相性。変化技から置き換えた攻撃だけは使用者の得意側を使う。
- 可変タイプ技：設定に`attackType: self`を持つ技は使用者の第1タイプ。原作の天候・持ち物・姿変化は導入しない。
- 割合技：現在HPの20%、上限200、HP1を残す。相性は掛けない。HP1なら使えない。
- 反撃技：直前の敵反撃で仲間が倒れた場合に強化倍率。防御成功では条件を満たさない。
- ひんし参照技：現在ひんしの人数で倍率を加算し上限18。復活で人数が減れば倍率も減る。
- 自爆系：威力24、使用者がひんし。自分以外に生存仲間がいない場合は使えない。
- 強化：次の10秒の通常攻撃だけ。発動者のひんしに依存せず、技の追加攻撃には掛からない。重ね掛け不可。
- 防御：次の反撃1回。重ね掛け不可、相手交代でも予約維持。
- 支援：自分・ひんし・満タンを対象外。支援された仲間は同じ合間に攻撃等を使えるが、2回目の支援はパーティ全体で不可。
- 復活：ひんしの1匹を選びゲージ0で復帰。全戦闘1回。使用済みはトレーナーの次の相手でも共有。全滅後に技を使う時間は設けない。
- 盤面：変換先と異なるマスから8マス、または36マス引き直し。指定タイプの生存担当がいなければ使用者の第1タイプへ変換。選択型は生存仲間の第1タイプ。
- 予約盤面：変更時点で実際の次盤面を決定し`pendingBoard`へ保存。次パズル開始時に反映して予約を消費。相手交代で通常盤面を作り直しても予約を優先。

盤面変換はブロックを消す行為ではなく、変換だけでダメージ・コンボ・ゲージを与えない。
味方ひんし・相性無効のブロックも通常のルールで消去・補充できる。ひんし属性はダメージとゲージ0、
相性無効はダメージ0だがその属性の生存仲間にはゲージが溜まる。

## 検証

`tests/pokemon-skills.cjs`で全1025代表技を有効な対象・状況で発動し、候補不足・無効操作・
上限・対象選択・再使用・支援連鎖・復活共有・割合HP1・自爆最後の1匹・物理特殊・盤面予約を検査する。
同じ予測結果を発動にも使い、失敗時はゲージ・使用回数・復活権を消費しない。
既存の種族値・タイプ・編成・図鑑・画像・音声・ボール交換も`npm test`に含む。

ブラウザでは390×664、320×568、844×390で6系統の実タッチ操作・ゲージ・予測と実ダメージ・
対象選択・発動ボタン・相手交代・最終報酬・図鑑の未遭遇非表示・サファリ30秒を確認する。
サファリは個別技を有効にせず、既存のなかよし量と画面を保つ。
