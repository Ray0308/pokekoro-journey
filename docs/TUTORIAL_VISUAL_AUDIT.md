# 初回の視覚案内と技UI

2026-11-21 / 0.9.2.98。ユーザーの「文字が読めなくても直感的に操作できるように」に対応。実際の子どもの理解度を確認した記録ではない。

## 変更

- 研究所の背景→博士→会話の順にフェード/登場。最初に博士が名乗る。話者ラベルと白い会話枠、本文15〜17px、濃い文字で区別。横持ちの最初の会話は左右配置。
- 最初に同じ3個をなぞる場所だけ明るくし、線・丸・手の見本を表示。成功後はスタート、技がたまった仲間、技カード、終了へと強調先を変える。実際に成功した時だけ既存の課題が進む。
- 関係ないところは暗くするが、視覚レイヤーでタッチを遮らない。スクロール/画面サイズ変更に追従。実パズル/カウント/発動中は消去し、集中を妨げない。技カードは説明を読めるようカード全体を明るくする。
- 技UIは仲間の姿、属性マークと色、種類、ゲージの量/数字、技名、対象、効果、発動/閉じるを整理。本編6カテゴリと研究所で共通。対象選択は効果説明より先、発動ボタンにも現在の対象名を表示する。
- 小画面で技の発動ボタンが画面下に切れる問題を検出。技選択中だけ敵領域を108pxに縮め、技画面は残りの高さへ収める。本文だけスクロールし、発動/閉じるは残す。通常のパズル盤面寸法は変えない。
- 森の最初にスタート/草むら/トレーナー/道具/交換所/ボスの6枚を実アイコンで説明。サイコロ5→5マスの図示と短い文。閉じたら実サイコロへ矢印を示す。mapIntroSeenで再開時の繰り返しを防ぎ、説明ボタンで再表示できる。

## 維持したこと

version 5の研究所模擬戦、相棒+ゴンベ、名前選択、実際のゲージ/技、ピカチュウ譲渡と捕獲練習、初回の3匹/ボール報酬。既存セーブを初期化せず、complete済みのユーザーへ再チュートリアルを強制しない。旧v3の練習とv2の互換経路は維持。技の効果・コスト・相性・10秒/30秒・敵のHPは変更しない。
