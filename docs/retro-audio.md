# 図鑑と自作BGMの音づくり

## 場面と曲

図鑑は `map-pokedex-chip-v1.mp3` を使用する。
図鑑を閉じたら、元のマップ曲を保存した再生位置から再開する。
新しい曲の読み込み中は、再生中の曲を維持する。
読み込み中に図鑑を閉じた場合は切替要求を取り消し、次回の表示を妨げない。

ジム・洞窟・アジト・リーグ・水辺の自作曲も同じ音源で作り直した。
曲の対応は `map-music-config.js`、切替・保存位置・音量は `map-audio.js` が担当する。
提供されたフィールド・戦闘・勝利・タイトルの音源は差し替えない。

## 音の方針と再生成

初期携帯ゲーム機を意識した矩形波2声・4bit三角波・ノイズの4声構成を使う。
音色と短いフレーズによるオマージュであり、既存曲の旋律や録音を転用しない。
音源の完全なハードウェアエミュレーションではない。
残響や厚い持続和音を抑え、単声の出力にまとめる。
ジムは前進するテンポ、洞窟は疎な低いフレーズ、水辺は3拍子で区別する。

```sh
npm run music:generate
node scripts/compose-map-themes.cjs pokedex
npm test
```

生成にはNode.jsとffmpegが必要。通常プレイには不要。
曲設定は `scripts/compose-map-themes.cjs`、音源は `tools/retro-synth.cjs` に分離する。
整形済みの別スクリプトを文字列置換して実行する方式は使わない。
新しい音源は新しいファイル名にして、既存の音源キャッシュを再利用しない。

## 図鑑の操作音・読み上げ

図鑑の開閉・ページ送り・読み上げ開始・入力エラーは短い矩形波のSEで返す。
汎用クリックSEとは重ねない。SE音量とサウンドOFFは既存の音声グラフで制御する。
読み上げの音量はSE側の設定を使い、0なら読み上げを止める。
読み上げ中もBGMを止めず、通常の24%へ下げる。
読み終わり、停止、ページ変更、閉じる操作、非表示、サウンドOFFで解除する。

## 確認項目

- 生成の再現性、鳴り出し、ピーク、ループ両端、6曲の存在を `tests/retro-music.cjs` で検査。
- ブラウザで図鑑の開閉・連続操作・曲の復帰・読み上げ・音量・ミュート・非表示復帰を確認する。
- 音源の準備前に図鑑を閉じてから再表示し、無音のままにならないことを確認する。
- マップ5種類から図鑑への往復、スマホ縦横・小画面・PCでの表示も確認する。
