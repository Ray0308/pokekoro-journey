# カントーのトレーナー編成と連戦

## 編集元

`data/trainer-rosters.json` が編成・候補・レベル・HP・時間の編集元。
全国図鑑番号で管理し、`data/pokemon.json` のマスタと照合する。
`trainer-rosters.generated.js` は生成物なので直接編集しない。

```sh
npm run trainers:generate
npm run trainers:check
npm test
```

生成時に図鑑番号、重複、御三家の例外、伝説・幻、素材、マップ設定を検査する。
ルールの実行テストでも全職業・全マップを抽選し、候補不足や到達不能な候補を検出する。

## 候補の決定

- マップの`jobs`から職業を決め、職業の`pool`から重複せずに抽選する。
- 職業の配置はマップ・周回・マスから安定して決める。描画の乱数でサイコロの結果を変えない。
- 同じマスのアイコン・職業・登場する立ち絵を一致させ、手持ち・匹数・レベルには抽選の幅を持たせる。
- `maxStage`と`stageWeights`で序盤は未進化中心、終盤は進化形中心にする。stageはゲーム内の進行区分で、進化APIの段階そのものではない。
- `classPoolIds`で職業ごとの場所限定候補を設定できる。不足分は同じ職業の`reserveIds`から補い、野生プールへ戻さない。
- ジム内は専用のジムトレーナー枠を使い、ジムの属性に合う候補へ限定する。既存の一般トレーナーの画像を再利用する。
- 伝説・幻は全トレーナー候補から除外する。御三家系統は一般候補から除外するが、おじょうさまのニャオハだけを明示的に許可する。

一般職業の匹数は提案どおり。むしとり・たんぱんは1〜3匹、ロケット団・やまおとこ・おじょうさま・かいパン・ひふきは2〜4匹、からておうは3〜5匹。
ムサシ達はポケモンタワーのイベント枠で各1匹と追加1匹。再戦・2周目以降は歴代候補を広げる。

## 固定ボスと重複禁止

初回ボスは`fixedIds`と`levels`を使い、野生抽選を参照しない。
最後の1匹が切り札で、再戦も維持する。再戦は先頭側の枠を`rematchIds`へ置き換える。
初回判定は周回数ではなく、そのボスへの勝利記録で行う。

ユーザー指定の重複禁止に合わせ、元の案の重複枠を次のように変更した。

| 相手 | 重複枠 | 代わりに採用 |
| --- | --- | --- |
| キョウ | 2匹目のドガース | ドラピオン |
| シバ | 2匹目のイワーク | ルカリオ |
| キクコ | 前座のゲンガー | ムウマージ |
| ワタル | 2匹目のハクリュー | ボーマンダ |

サカキのアジトは3匹、シルフは4匹、ジムは5匹。
ライバルはサントアンヌ号で4匹、ワタルの次のチャンピオン戦で6匹。
相棒ゴンベとの相性判定や、プレイヤーの御三家選択画面は追加しない。
ライバル自身の御三家の系統と、中盤・終盤の抽選済み編成を保存する。

## 連戦と報酬

`trainer-rules.js`が編成、`trainer-battle.js`が交代演出を担当する。
`app.js`の既存バトルを1匹ずつ再初期化し、各相手でパズル・HP・コンボをリセットする。
レベルはHPの計算に使い、表示だけの値にしない。
先発の時間・HPと切り札の時間・HPはJSONの`battle`に分離してある。
初期値は一般の前座20秒・ボスの前座15秒・切り札30秒。難易度の細かな調整は別途行う。

途中の撃破では勝利BGM・アイテム・バッジ・チケット・次マップを確定しない。
相手のボール数と残数を表示し、交代中も戦闘曲を続ける。
全員倒した時だけ、従来と同じ量の勝利報酬を一度付与する。
途中で負けた場合は既存の参加報酬1個に進み、ボス勝利は記録しない。
トレーナー戦は既存どおり勝利報酬、野生戦は捕獲へ進む。敵の複数体化に伴う捕獲ルールの追加はしない。
サファリとにじのくもの抽選・非戦闘ルールも維持する。

`battleEpoch`で前の演出を破棄し、交代直後は`roundStarted`で古い完了通知による飛ばしを防ぐ。
デバッグの即撃破は現在の1匹を倒す。繰り返すことで各交代と最後の報酬まで確認できる。

## セーブ互換

既存の所持・パーティー・持ち物・位置・マップIDは維持する。
`trainerWins`、`rivalStarterId`、`rivalTeams`だけを補完する。
旧セーブのクリア済みマップは、そのボスへ勝利済みとして移行する。
デバッグは従来の専用保存先を使い、通常セーブへ書き戻さない。
ワタルの次へチャンピオン戦を挿入したが、旧セーブに保存済みの移動先は書き換えない。

## 検査

`tests/trainers.cjs`と`tests/trainer-cases.js`で固定編成、重複禁止、候補範囲、予備候補、序盤の進化制限、全9世代の実抽選、同マップの変化、ライバルの保存、旧セーブを検査する。
ブラウザでは途中の撃破・最後の報酬・途中敗北・連戦BGM・撤退・非表示・デバッグ・特殊ステージ・小画面を確認する。

相手1匹ごとの初回パズルは`battle.puzzleStarted`で判定し、3・2・1・GOを表示する。
連戦全体で共有する`combat.turn`をカウントダウンの省略条件に使わない。
同じ相手との2ターン目以降だけGOに短縮し、計測はカウントダウン後から開始する。

0.9.2.35以降、途中の撃破は技画面を挟まず次の登場へ進む。
送球・登場の後は戦闘画面へ自動で戻すが、パズルはスタートを押すまで始めない。
待機中に仲間をタップすると技を確認・使用できる。新しい相手への攻撃技も有効。
スタート後は相手ごとの初回に3・2・1・GOを表示する。
