# 10秒ターンとゲージ技

## 範囲

1ターンのパズルは10秒。固定ターン上限は設けず、戦える仲間がいる限り継続する。
編成・レベル・報酬は既存値。敵HPには種族値による補正を適用し、細かな難易度調整は別工程。
`trainer-rosters.json`の旧`seconds`は現在の戦闘時間には使わない。
サファリは戦闘ではなく、従来の30秒のなかよし処理を保つ。

## 進行と保存

`ready → charging → resolving → skills → counterattack → ready`。
敵を倒したら最後だけ勝利へ、次がいる場合は支援技を使ってから次の登場へ進む。
技選択中に制限時間はない。通常攻撃後に敵HPが残っても即敗北にはしない。
累積HPダメージは同じ敵に対して持ち越す。捕獲は従来どおり野生勝利後のみ。

`battle.combat`と`series.combat`だけで生存・技ゲージ・ターン・支援効果を共有する。
`state.party`やポケモンマスタにひんしを書き込まない。セーブ形式は変更しない。
撤退・敗北・勝利後に新しい戦闘を始めれば全員がゲージ0・ひんしなしに戻る。
全員ひんしで敗北。「めのまえが まっくらになった…」と戦闘画面全体を暗転し、結果画面へ進む。
無防御・復活なしなら3匹は3回、6匹は6回の反撃で全滅するが、これは固定上限ではない。
防御等で生存が続けば7ターン目以降も継続する。「さいきのいのり」で生存メンバーが戻れば、その分も継続する。

## ゲージと個別技

各ポケモンは代表技を1つ持つ。必要ゲージ・効果・対象は`data/pokemon-skills.json`で管理する。
1025種の割当と、候補を含めた668種類の能力設定を`npm run skills:generate`で同期JSへ生成する。
実際に代表技として使われるのは492種類。同じ技IDは誰が使っても同じ必要ゲージ・効果とし、
攻撃の数値には使用者の種族値と相手の防御/特防を反映する。

同タイプのブロック1個につき、素早さに応じて0.85〜1.4を加算する。
上限は各技の必要ゲージ（8〜24）で、表示は整数・端数は`gaugeProgress`で保持する。
ひんしではゲージと端数を0にし、消しても加算しない。ひんしのタイプも盤面から除かない。

| 系統 | 動作 |
| --- | --- |
| 攻撃 | 技のタイプ・物理/特殊・倍率で追加攻撃。予測と発動で同じ判定を使い、無効なら消費せず使用不可 |
| 強化 | 次の10秒パズルの通常攻撃1回を強化。技ダメージには掛からず、使用者が倒れても予約は残る |
| 防御 | 次の反撃1回を無効。すでに準備済みなら重ね掛け不可 |
| 盤面変更 | 異なる8マスの変換または36マスの引き直し。次のパズル用に予約し、相手交代でも引き継ぐ。変換だけで消去・ダメージ・ゲージは発生しない |
| サポート | 自分以外の生存仲間のゲージを増やす。単体は対象選択、全体は未満タンの生存仲間だけ。上限を超えない |
| 復活 | ひんし1匹を選び、ゲージ0で復活。パーティ全体で1戦闘1回、相手交代でも使用済みを保持 |

1匹につき1回のパズルの合間に技1回、サポートはパーティ全体で1回。
支援で溜まった仲間の攻撃等は使用できるが、サポートを連鎖させない。
強化の重ね掛け、対象なし、盤面が変化しない変換、無効相性、HP1の相手への割合攻撃などでは
ゲージ・使用回数・復活権を消費しない。引き直しは有効な別属性があれば最低1マスを変える。

技はパズルの攻撃解決後に選ぶ。相手を倒した合間も、次の相手がいる場合は支援や盤面予約を使える。
最後の相手へのとどめは即勝利に進む。次へ進むとき、相手が残っていればランダムに1匹が反撃でひんしになる。
全滅だけが敗北で、固定ターン上限はない。

例：ゴンベの「たくわえる」は12で次の通常攻撃×1.5、フシギダネの「つるのムチ」は10で物理のくさ攻撃×8。
プラスルの「てだすけ」は10でほかの1匹のゲージ+6、パーモット/ベラカスの「さいきのいのり」は20で復活する。

原作のPP・命中・状態異常をそのまま再現するものではない。回復技は個別HPがないため支援へ、
眠り等は防御へ置換するなど、本作用の暫定設定である。細かな数値調整は別工程。
出典・分類・特殊な攻撃モードは[個別技のデータと計算](pokemon-skills.md)を参照。

## 実装上の注意

- 通常攻撃と追加技の勝利は同じ終了処理へ集約。全員倒した時だけ勝利BGMとトレーナー報酬を確定する。
- 待機後は`battleEpoch`、チャージ光の到着はターン番号も照合して古い処理を破棄する。
- 技使用・反撃は専用phaseで二重入力を止める。次の戦闘では無効にしたボタンも初期化する。
- 技メニューでは盤面のtouchstart抑止を適用せず、実機のタップやメニュー内スクロールを許す。
- ピースの正規のなぞり・隣接・3つ以上の消去ルールは維持する。

`tests/battle-turns.cjs`で計算と戦闘内の状態を検査する。画面では10秒の開始、合間の技、
反撃、ひんし、同じ属性の生存、交代、技でのとどめ、7ターン目以降の継続・全滅暗転、撤退後の復帰を確認する。

攻撃に寄与しない属性も同じ隣接・3個以上ルールで消去・補充できる。
生存メンバーがいない属性はダメージ0・ゲージ加算なし。相性無効もダメージ0だが生存メンバーのゲージは溜まる。
暗転中の二重入力と、新しい戦闘へ古い終了処理が混ざることを防ぐ。
