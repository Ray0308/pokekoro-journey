# ポケモンの名前・タイプ・説明

## 編集元と照合範囲

- `data/pokemon.json`: 提供されたGoogleシート「シート1」B3:F1027の全1025種。
- `data/pokemon-reference.json`: PokéAPIの通常フォルムの日本語名と、順序を含むタイプ一覧。
- `data/pokemon-sheet-corrections.json`: 元シートへ実施した64セルの修正記録。
- `data/pokemon-description-corrections.json`: 2026-11-14の説明見直し。固定コミット・版・言語・原文・修正前後・理由を保存。
- `pokemon-data.generated.js`: ゲーム用に生成したデータ。直接編集しない。

元シート: https://docs.google.com/spreadsheets/d/1zdl2GwCz7ievmw0qTRpmpd0LvfYh2zBYgU1rP6QTqCI/edit

2026-11-13に全1025種の名前・タイプを照合した。バンギラスの第2タイプを「じめん」から「あく」へ修正し、
63件の名前の末尾にあった改行を除去した。セルの書式・色・入力規則は維持した。
照合に使ったCSVのURLとSHA-256は参照JSONへ記録している。
PokéAPIリポジトリのライセンス全文は [pokeapi-data.txt](licenses/pokeapi-data.txt) に保存している。

説明文はユーザー提供の要約に、出典付きの修正文を加えたもの。公式の原文と編集要約を区別する。
2026-11-14に全1025件を通読し、身体・生息地・行動・進化前後やフォームの混同を見直した。
233件は空白を除けばPokéAPIの日本語図鑑文と一致し、これらは変更しない。
説明を92件修正した。59件は日本語図鑑文の空白・改行だけを整えたもの、33件は英語図鑑文に基づく日本語要約。
後者は公式の日本語原文ではない。正しい要約を含む残り933件は維持する。
残した要約の全ての細部が、一次資料と逐語照合済みという意味ではない。

出典はPokéAPIの `pokemon_species_flavor_text.csv`、コミット
`8a92bfa7dab2f12b84b5d151562f9857c133ff30`。修正記録にURLと元CSVのSHA-256を記載する。
このスナップショットの漢字日本語（language_id=11）はNo.898まで、英語（9）はNo.1025まである。
日本語を優先し、未収録の世代のみ同じ種の英語文を要約した。版IDは同リポジトリの `versions.csv` に対応する
（23=X、24=Y、27=Sun、30=Ultra Moon、33=Sword、34=Shield、39=Legends: Arceus、40=Scarlet、41=Violet）。
原文の伝聞・不明・学説を断定へ変えない。たとえばガチグマの月光による変身や、
チヲハウハネの飛行能力などを本文の根拠なしに追加しない。

ルージュラの「ガラルの ルージュラ」とケンタロスの「ガラルに 暮らす」はシールド図鑑に実在する。
地名だけでリージョンフォームの混入と判定して削除しない。
ヤンヤンマの家を空へ持ち上げる風の説明もLegends: Arceusの英語原文にあり、維持する。
その一方で、ポッタイシの群れ、バイバニラの頭の数、アルクジラの海上生活などは訂正する。

説明を直す場合は根拠と差分を記録し、シートの対応する説明セル（F列、行=全国図鑑No.+2）と
ローカルJSONを同期する。名前・タイプ・セル書式を巻き込まない。
元シートの「公式照合ログ」は従来の名前・タイプの照合記録であり、全説明の逐語照合済みを意味しない。

## 再生成

```sh
npm run data:generate
npm run data:check
npm test
```

生成スクリプトは通信もシートの変更も行わない。シートを更新したら、対象範囲を再読込してJSONを更新する。
名前・タイプが参照データと一致しないと生成を停止する。参照側を更新する場合も差分と根拠を確認する。
全国図鑑番号をセーブのキーとして維持し、フォームの別IDを持ち込まない。

`index.html`では生成ファイルを`pokemon-data.js`より先に読み込む。
API側のタイプ番号はゲームと異なるため、そのままコピーせず日本語タイプ名からゲームの番号へ変換する。
その対応が`party-rules.js`と一致することもテストする。

属性の補完により、全種の主・副属性がパーティー集計・火力・属性ボールの判定に反映される。
攻撃力`power`、敵HP、捕獲率の式、出現プール、18タイプ相性の導入範囲は変更しない。
種族値・特性・技・進化のゲームルールへの追加は、この取り込みには含めない。
