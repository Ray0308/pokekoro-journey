## 守る制約

- ゲージ速度は種族値由来のまま。技コスト変更は初期化や所持変更を伴わない。
- 吸収系は攻撃が成立したときのみ、自分以外・生存・未満タンのうちゲージ充填率が最低の1匹へ配布。率が同じなら編成順。満タンを超えず、本人へ還元しない。候補なしなら攻撃のみ。
- 複合防御もガード中は使えず、効果なしの消費/配布はしない。
- 強化倍率は掛け合わせず最大値。1.25倍の防御後にも、より強い強化技で上書きできる。次のパズル1回で消費。
- 支援は引き続きパズルの合間に全体で1回。ひんしは復活技以外で戻さない。
- 相手交代で戦闘中のゲージ/ガード/強化をリセットしない。
- 弱点・無効・物理/特殊・種族値由来の火力は従来通り。
