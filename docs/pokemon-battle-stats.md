# 種族値と本作のバトル

## 取得元と生成

通常姿の全国図鑑No.1〜1025を対象に、HP・攻撃・防御・特攻・特防・素早さの6項目を取り込む。
PokéAPIの固定コミット`8a92bfa7dab2f12b84b5d151562f9857c133ff30`の
[`pokemon_stats.csv`](https://raw.githubusercontent.com/PokeAPI/pokeapi/8a92bfa7dab2f12b84b5d151562f9857c133ff30/data/v2/csv/pokemon_stats.csv)を
`data/reference/pokemon-stats.csv`に保存した。種族名・姿の対応は同じ版の`pokemon.csv`の
pokemon_id=species_id、is_default=1で照合済み。別姿・メガ・合体などのIDは対象にしない。

`npm run stats:generate`で出典とハッシュ付きの`data/pokemon-stats.json`、同期読み込み用の
`pokemon-stats.generated.js`を生成する。`npm run stats:check`はCSVハッシュ・全1025×6項目・
重複・欠落・値域・生成物の一致を検査。プレイ中のAPI通信は行わない。
元の名前・タイプ・説明のシートやJSONを書き換えず、`POKEDEX[i].stats`に読み取り専用で接続する。

## 計算

`pokemon-battle-stats.js`に変換を集約。原作のダメージ式・個体値・努力値・育成レベルは導入していない。

| 項目 | 本作での使用先 |
| --- | --- |
| 攻撃・特攻 | 大きい方を得意側に設定。攻撃が同値以上なら物理、特攻が大きければ特殊。通常パズル攻撃に使用。個別技はその技の物理/特殊分類で参照する |
| 防御・特防 | 相手が物理を受けるなら防御、特殊を受けるなら特防を使用。同じブロックに反応する味方も、一匹ずつ計算して合算 |
| HP | 敵として登場したときの最大HPへ補正。トレーナーのレベル・エースによる既存の基準HPは保持 |
| 素早さ | 同タイプのブロックを消したときの技ゲージ増加量。上限・消費は個別技の必要ゲージ |

- 火力：`11 × (0.5 + 得意側 / 160) × clamp(160 / (80 + 対応する防御側), 0.55, 1.45)`。
- その後、既存の主副タイプ寄与、つないだ数、コンボ、多属性編成補正、タイプ相性、次ターン強化を適用。
- 攻撃技：技の物理/特殊分類で上の火力を求め、個別倍率と技タイプ相性を適用。予測表示と実ダメージは同じ判定を使用。
- 敵HP：`round(基準HP × clamp(0.7 + HP種族値 / 240, 0.75, 1.6))`。通常野生の基準は365、野生ボス620、トレーナーは既存の基準を使用。
- ゲージ：1個あたり`clamp(round(800 + 素早さ × 10 / 3), 850, 1400) / 1000`。整数演算で端数を持ち越し、消し方による損失を防ぐ。

技の物理/特殊分類と必要ゲージは、0.9.2.33から[個別技設定](pokemon-skills.md)に接続する。
通常パズル攻撃の得意側自動選択と、個別技の固定分類は区別する。

## 維持するルール

反撃でランダムな生存メンバー1匹がひんしになるルールは維持。味方に個別HPを追加せず、
味方のHP・防御・特防で反撃のひんしを回避する計算は行わない。
この3項目は同じポケモンが敵として登場したときの耐久へ反映される。
特性を実装していないため、ヌケニンのふしぎなまもり・原作のHP1なども再現しない。

1ターン10秒・全滅まで継続、初期ブロックプール、ひんし・ゲージの戦闘内共有、終了後の復帰、
トレーナー編成・レベル・報酬・捕獲・セーブIDを維持する。
サファリには種族値による火力・HP・ゲージ補正を適用せず、従来の30秒なかよし量を使う。

図鑑の「つよさを みる」で6項目・得意側・ゲージ速度を確認できる。未遭遇では表示しない。

## 検証

`tests/pokemon-battle-stats.cjs`は全1025種の数値・代表例・入力エラー・物理特殊の防御参照・
HP・速度・端数持ち越し・無効相性・ひんし後の蓄積停止を検査する。
既存のタイプ・トレーナー・図鑑・捕獲・音声のテストと併せて`npm test`で実行する。
ブラウザでは実際のタッチ消去・攻撃技の予測と実ダメージ・連戦時の端数共有・復帰・サファリ・
図鑑の開閉と縦横の小画面を確認する。
