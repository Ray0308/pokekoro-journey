# タイトル素材

## 現在の素材

| 種類 | ファイル | 状態 |
| --- | --- | --- |
| ロゴ | `../title-logo.webp` | 既存の透過ロゴを再利用 |
| 冒険風景 | `background-v2.webp` | ユーザー提供の完成背景。元のJPEGは `originals/background-v2.jpg` |
| 雲 | `placeholders/clouds.webp` | 独立したコード製タイル。左側の空だけをゆっくり横移動 |
| 主人公の待機／開始／ちら見 | `sprites/hero-*.webp` | ユーザー提供画像 |
| 相棒の待機／食べる | `sprites/companion-*.webp` | ユーザー提供画像。正式採用、常に表示 |

素材パスとアニメーション速度は `title-config.js` に集約しています。背景は縦横比を保って画面を覆います。手前の丘だけは同じ提供画像の草地から切り出して重ね、街の上にキャラクターが浮かないよう接地させています。描き直しは行いません。旧 `placeholders/` の山・森・川・草原は現在読み込まず、過去の仮素材として保管しています。

## キャラクターの保持

`originals/` に受け取ったJPEGをそのまま保存しています。描き直し・色変換・生成は行っていません。表示用WebPでは、外縁からつながった白い背景のアルファだけを除去し、無損失で保存しています。帽子や服の内部の白は保持します。

待機／開始の主人公画像は `690×960`、同じ切り出し位置 `+280+150` を使用し、同じ枠に重ねます。ちら見は同じ大きさで `+280+144` を使い、18ピクセル分の表示オフセットで足元を合わせています。相棒の食べる画像は待機時の描画比率へ合わせ、食べ物や記号が右へ広がっても本体の大きさを変えません。

## タイトルの動作

- 雲は同じタイルを2回繰り返し、1タイル分移動してループします。木や山の上を横切らないよう左上の空に限定します。
- 開始演出は初期値1400ms。ボタン押下・サイコロの跳ね・主人公の歩き出しの後、既存の冒険画面へ進みます。
- 待機中は10〜18秒おき、またはゴンベをタップすると相棒が2秒食べ、元へ戻った150ms後に主人公が850msちらっと見ます。`idleScene` で間隔を調整できます。
- ダイアログ中、画面を離れたとき、開始演出中、動きを減らす設定中は待機演出を停止します。
- 設定キーは `pokekoro-title-v1`。現在保存する設定はサウンドだけです。旧 `companion:false` は無視し、相棒を必ず表示します。
- ゲーム進行キー `pokekoro-v1` は変更しません。
- アクション画像を読み込めない場合は待機画像のまま開始できます。

## 検証

ブラウザでスマホ縦・PC・横向き、設定の移行、掛け合い、開始／戻る、ゲームデータ保持を確認します。iPhone Safari実機での最終確認は別途必要です。

## タップ再生の排他制御（0.2.4）

ゴンベはキーボードでも操作できるボタンです。自動再生・タップ再生は同じ処理と再生中フラグを使います。食べる・戻る直後の間・主人公のちら見の全期間、ボタンを無効化し、JS側でも連打を無視します。次回の予約や途中からのやり直しは行いません。終了後に操作を戻し、自動再生までの待ち時間を新たに取ります。動きを減らす設定では自動再生は停止しますが、明示的なタップによる静止ポーズ切替は利用できます。

## 丘への接地（0.2.5）

`foreground-hill-v2.webp` は提供背景の下部（853×230、+0+1050）の草地を無損失で切り出した素材です。新しく描画・生成した草ではありません。画面幅に合わせて手前へ重ね、輪郭を丘形にクリップし、下端を背景へなじませます。主人公とゴンベの足元には個別の影を置き、待機時は足の接地点を動かさない小さな伸縮で生命感を出します。

0.2.6では、新規提供背景を `background-v2.webp` として使用し、草地の切り出しも同じ新背景から作り直しました。元の背景は保管しています。開始演出のみ1.4秒へ延ばし、ゴンベの掛け合い（2秒＋150ms＋850ms）は変更していません。
