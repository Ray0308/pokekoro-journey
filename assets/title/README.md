# タイトル素材と差し替え

## 使用中の素材

| 種類 | ファイル | 状態 |
| --- | --- | --- |
| ロゴ | `../title-logo.webp` | 既存の透過ロゴを変更せず再利用 |
| 主人公の待機 | `sprites/hero-idle.webp` | 今回提供された背面待機画像 |
| 主人公のアクション | `sprites/hero-action.webp` | 今回提供された背面アクション画像 |
| 青い相棒 | `sprites/companion-back.webp` | 今回提供された背面画像。オプションで非表示可 |
| 空 | `title.css` のグラデーション | コード製の仮表現 |
| 雲・山・森・川・草原 | `placeholders/*.webp` | **差し替え用の仮素材**。原稿は同名の `.svg` |

山・森・川・草原は同じ900×1400のキャンバスと座標系を使用し、各レイヤーを画面全体へ重ねます。個別の引き伸ばしや切り詰めを行うと継ぎ目が出るため避けてください。

画像パス、初期表示、アニメーション速度はルートの `title-config.js` に集約しています。背景を完成素材へ置き換える場合はレイヤーのキーを維持したままパスを変更してください。雲は独立した横方向のタイルとして使い、山や森に焼き込まないでください。

## キャラクターの扱い

`originals/` に受け取ったJPEGをそのまま保存しています。キャラクターの描き直し・色変換・生成は行っていません。

表示用WebPは、外縁からつながった白い背景のアルファだけを除去し、無損失で保存しました。内部の帽子や服の白は保持します。主人公の2枚は同じ `690×960`、同じ切り出し位置（元画像の `+280+150`）を使用し、同じ固定枠に重ねて切り替えます。足元の位置も保持します。元のJPEGの圧縮に由来する輪郭は再描画していません。

処理には ImageMagick の floodfill と lossless WebP を使用しています。背景の白を除く以外のピクセル描画は行いません。後から透過済みの原本を受け取った場合は、同じ足元とキャンバスに合わせて差し替えてください。

## タイトルの動作

- `title.css` はタイトル専用。ゲーム本体のCSSから旧タイトル用ルールを除去しました。
- 雲は同じタイルを2回繰り返し、ちょうど1タイル分を移動してループします。
- 開始演出は初期値950ms。短いボタン押下、サイコロの跳ね、主人公の画像切替と歩き出しの後、既存の冒険画面へ進みます。
- `prefers-reduced-motion` では雲・待機・開始の大きな動きを停止し、120msで遷移します。
- 開始の連打は1回として扱います。戻ると待機状態へ戻ります。
- 設定保存キーは `pokekoro-title-v1`。ゲーム進行キー `pokekoro-v1` は変更しません。
- アクション画像が読み込めない場合は待機画像のまま開始できます。

## 検証の限界

ブラウザ自動テストで縦横の表示領域、開始・戻る・オプション・設定保持・保存データの保持を検証します。iPhone Safari実機での最終確認は別途必要です。完成背景の入稿待ちを理由にタイトルの利用を止める構造にはしていません。

## ときどき見せる待機ポーズ（0.2.2）

- 10〜18秒待った後、相棒の食べるポーズを2秒表示します。
- 待機へ戻し、150ms後に主人公のちら見を850ms表示して元へ戻します。
- `title-config.js` の `idleScene` で全ての間隔を変更できます。
- `originals/companion-eat.jpg` と `originals/hero-glance.jpg` は追加提供された元画像です。描き直しはせず、同じ方法で外背景を透過しています。
- 食べる画像は描画サイズを待機時の比率へ合わせ、追加の食べ物・記号が右へ出ても本体の大きさを変えません。ちら見は690×960（+280+144）で切り出し、表示時に18ピクセル分だけ上へ寄せて足元を維持します。
- 開始ポーズは既存の `hero-action.webp`（今回再送された画像と同一）を継続使用します。
- 相棒を非表示にしたとき、画面を離れたとき、各ダイアログ中、開始演出中、動きを減らす設定中は再生しません。戻ると新しい待ち時間から再開します。
